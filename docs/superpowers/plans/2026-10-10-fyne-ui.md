# Fyne UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the g3n-gui widget layer of `desktop/native/ui/` with a full-parity Fyne UI styled as authentic Borderlands 2, keeping the g3n 3D viewer as a companion window.

**Architecture:** One binary (`cmd/bl2native`): Fyne owns every editing screen (save list, CHARACTER, INVENTORY, SKILLS, ACHIEVEMENTS, status bar); g3n viewer moves to `desktop/viewer/` and opens as a second window from a button. `session.Session` stays the single mutation API (gains 4 read methods + 1 edit method). g3n-gui widget code is deleted; g3n engine (`core/renderer/gltf/window`, lit scene) is retained.

**Tech Stack:** Go 1.25, `fyne.io/fyne/v2` (new), `g3n/engine v0.2.0` (kept), existing `native/session`, `native/setup`, `internal/{editor,assets,platform}`.

**Spec:** `docs/superpowers/specs/2026-10-10-fyne-ui-design.md`

## Global Constraints

- Palette source of truth = `static/style.css`; success green is `#3bbd40` (not `#4c6`-style shorthand); rarity map: common `#9d9d9d`, uncommon `#3bbd40`, rare `#4b8be8`, very-rare `#9b59b6`, legendary `#e8a33a`, e-tech `#d94fff`, seraph `#ff4081`, pearl `#00e5ff`, effervescent `#ff6ed4`.
- Fonts bundled offline (Oswald + Rajdhani via `fyne bundle`), never fetched at runtime. Dark-only theme.
- Window: default 1280×800, min 1024×700.
- Platform package remains untouched: game-writes blocked by `platform.IsGameRunning()` inside `session.SetCharacter`; save filenames must match `^Save\d{4}\.sav$`.
- Wails track (`internal/bridge`, `frontend/`, `main.go`) untouched. g3n gui widget files (`native/ui/{character,inventory,tabs,shell}.go` gui spellings) fully removed — no dual widget layers.
- Every task: `go test ./...` and `go vet ./...` green; commits are small and conventional (`feat(native): ...`, `refactor(native): ...`, `test(native): ...`).
- Inventory DOMAINS = sessions `SaveView.Inventory` keys must stay table-column source: `Weapons`, `Items`, `Bank` (verify exact keys at Task 3 against `editor.ExtractInventory`; `invCats()` in current `inventory.go` shows the old field mapping).

## Review Focus

- **Tab contents must die on save switch** — selecting another save rebuilds CHARACTER content from the fresh `SaveView`; a stale widget holding the old filename would write the wrong file. → Task 6 test: `TestRenderSaveSwitchRebuilds`.
- **Game guard disables edits everywhere** — while `platform.IsGameRunning()` (checked every 3s) the CHARACTER form and INVENTORY action buttons must be disabled with a gold chip; inputs left live would race in-game state. → Task 6 test: `TestGuardDisables`.
- **Session read methods never leak constructor config errors** — `EnableAchievements`/`GetSkills`/`ListAchievements` return session-setup errors (nil session/config), not panics, when `s.store` is nil. → Task 1 tests in each: unset config → error.
- **Viewer close ≠ app quit; relaunch = fresh window** — closing the g3n window must leave Fyne running; opening "View 3D" twice must not double-wire the scene or panic a closed window. → Task 1 test: `TestOpenTwiceSecondFails`/callback-based.
- **Skill points/clamp semantics** — `SetSkills` clamps negative levels to 0; UI must cap a set at the skill's `max` from `skill_trees.json` and disable points at `SkillPoints==0`. → Task 8 test: `TestSkillProjection`.
